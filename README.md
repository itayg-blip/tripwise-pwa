# TripWise

אפליקציית PWA דו־לשונית לניהול תקציב טיול זוגי. האפליקציה תומכת בכניסה חד־פעמית עם Google, שמירת סשן וסנכרון נתונים לכל משתמש באמצעות Firebase.

## הפעלה מקומית

ב־macOS אפשר ללחוץ פעמיים על `start-tripwise.command`. הקובץ מפעיל שרת מקומי ופותח את האפליקציה בכתובת המתאימה. יש להשאיר את חלון ה־Terminal פתוח בזמן השימוש.

לחלופין:

```bash
cd tripwise
python3 -m http.server 8765
```

פתחו `http://localhost:8765` בדפדפן במחשב.

אין לפתוח את `index.html` ישירות כ־`file://`: דפדפנים חוסמים במצב זה את OAuth, Web Worker וקבצי WebAssembly, ולכן Google SSO ו־OCR לא יפעלו. יש להשתמש בגרסת ה־PWA המקוונת או ב־localhost.

## התקנה בטלפון

יש להעלות את התיקייה לאחסון HTTPS סטטי (למשל GitHub Pages, Netlify או Cloudflare Pages):

- iPhone: פתחו ב־Safari → Share → Add to Home Screen.
- Android: פתחו ב־Chrome → Install app.

## פריסה ל־GitHub Pages

התיקייה כוללת workflow מוכן ב־`.github/workflows/pages.yml`. לאחר העלאת התוכן ל־repository והפעלת GitHub Pages עם מקור `GitHub Actions`, כל push ל־`main` יפרוס אוטומטית את הגרסה העדכנית ב־HTTPS.

כל הנתיבים באפליקציה יחסיים, ולכן היא עובדת גם בכתובת פרויקט כגון `https://USERNAME.github.io/tripwise/`. קובצי ה־OCR נשמרים ומורצים בדפדפן ולא נשלחים לשרת.

## מה כלול

- עברית ואנגלית עם RTL/LTR מלאים.
- תהליך onboarding להגדרת יעדים, תאריכים, תקציב והתראות יומיות/שבועיות.
- רקע header מקומי שמתחלף אוטומטית לפי היעד הראשון שנבחר.
- תקציב כולל ודינמי ליום לפי היתרה והימים שנותרו.
- מטבעות ושערים סטטיים מובנים.
- תמיכה במטבעות אמריקה הלטינית, עם MXN ו־GTQ בראש הרשימה וכן BRL, ARS, CLP, COP, PEN, UYU, BOB, PYG, CRC, HNL, NIO ו־DOP.
- שלושה מצבי תצוגת הוצאה: מטבע מקומי + המרה לשקל, שקל בלבד או מטבע מקומי בלבד.
- השערים הם שערי ייחוס סטטיים ל־2026-10-05 ונועדו לתכנון תקציב, לא לביצוע עסקת מטבע.
- שני משלמים, מאזן זוגי וחישוב התחשבנות.
- העלאת צילום מסך/קבלה ו־OCR אמיתי שמורץ מקומית באמצעות Tesseract.js והמודל האנגלי המצורף לאפליקציה.
- חילוץ כמה עסקאות מצילום בנק אחד, כולל שם בית העסק, סכום ותאריך, עם מסך סקירה ועריכה לפני שמירה.
- סיווג אוטומטי של סוג ההוצאה לפי שם בית העסק וטקסט הקבלה.
- מיקום יומי בהרשאה ושמירה מקומית.
- מדדים ניתנים לבחירה למסך הבית.
- תובנות לפי קטגוריה/יום, מפת מקומות, ייצוא/ייבוא JSON.
- מצב offline מלא לאחר טעינה ראשונה, כולל מנוע ה־OCR והמודל המקומי.
- Google SSO עם סשן מתמשך, הפרדת מידע לפי משתמש וסנכרון בזמן אמת בין מכשירים.
- היסטוריית פעולות בענן לכל משתמש תחת הרשאות Firestore מבודדות.

## הגדרת התחברות וסנכרון

לפני פריסה יש להזין את פרטי Firebase Web App בקובץ `firebase-config.js`, להפעיל Google Authentication ולפרסם את `firestore.rules`. ההוראות המלאות נמצאות ב־`FIREBASE-SETUP.md`.

## מגבלות MVP

- ללא הגדרת Firebase האפליקציה מאפשרת מצב מקומי לצורכי בדיקה בלבד; אין בו סנכרון בין מכשירים.
- התקנת PWA דורשת כתובת HTTPS. הפקת IPA/APK חתום דורשת סביבת build וחתימת מפתח.
